## 2. ความเข้าใจโจทย์ของฉัน

โจทย์ให้พื้นที่กระเบื้องขนาด N x N แต่ละช่องคือจำนวนจุดที่เคาะแล้วเสียงไม่สมบูรณ์ (0-5 จุด) แล้วให้สรุปผลเป็นรายแถว รายคอลัมน์ และผลรวมทั้งหมดพร้อมค่าปรับ

input: บรรทัดแรกคือ N เป็นint กับ P เป็นfloat คือค่าปรับต่อจุด ต้องใช้split แยก
อีก N บรรทัดเป็นตัวเลข N ตัว รับมาเป็นlist int แล้วเก็บเป็นlist 2 มิติ

output: N บรรทัดแรกคือข้อมูลแถวเดิม ต่อท้ายด้วยจำนวนกระเบื้องที่เสีย กับจำนวนจุดที่เสียของแถวนั้น
บรรทัด N+1 คือจำนวนกระเบื้องที่เสียแต่ละคอลัมน์ บรรทัด N+2 คือจำนวนจุดที่เสียแต่ละคอลัมน์
บรรทัดสุดท้ายคือ จำนวนกระเบื้องที่เสียทั้งหมด จำนวนจุดทั้งหมด และค่าปรับทศนิยม 2 ตำแหน่ง

constraints: ต้องแยกให้ออกระหว่าง "จำนวนกระเบื้อง" ที่นับแค่ช่องที่มากกว่า 0 กับ "จำนวนจุด" ที่เอาค่ามาบวกกัน
และค่าปรับคิดจากจำนวนจุดคูณ P ไม่ใช่จำนวนกระเบื้องคูณ P
