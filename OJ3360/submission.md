## 2. ความเข้าใจโจทย์ของฉัน

โจทย์ให้หั่นขนมปังขนาด W x H ด้วยใบมีดแนวตั้งกับแนวนอน แล้วให้หาว่าชิ้นที่ใหญ่ที่สุด 2 ชิ้นมีพื้นที่เท่าไหร่

- input: บรรทัดแรกเป็นจำนวนเต็ม 4 ค่าคือ W H M N บรรทัดที่สองเป็นตำแหน่งมีดแนวตั้ง M ค่า บรรทัดที่สามเป็นตำแหน่งมีดแนวนอน N ค่า ต้องใช้split แยกค่าทุกบรรทัด
- output: พื้นที่ของชิ้นที่ใหญ่ที่สุด 2 ชิ้น โดยให้print ตัวที่มากกว่าก่อน
- constraints: ชิ้นที่ใหญ่สุด 2 ชิ้นอาจมีพื้นที่เท่ากันได้ และต้องนับขอบขนมปังคือ 0 กับ W และ 0 กับ H ด้วย ไม่งั้นจะได้ความกว้างไม่ครบ

## 3. แผนแรกของฉัน

```text
1: รับค่า W H M N แล้วรับตำแหน่งมีดทั้งสองแนวเป็นlist int
2: เพิ่ม 0 ไว้หน้าlist และเพิ่ม W หรือ H ไว้ท้ายlist เพื่อให้นับขอบขนมปังด้วย
3  ใช้for loop หาความกว้างของแต่ละช่องโดยการเอาตำแหน่งถัดไปลบตำแหน่งปัจจุบัน ทำแบบเดียวกันกับความสูง
4เอาความกว้างทุกตัวคูณกับความสูงทุกตัว ใส่ลงlist พื้นที่ทั้งหมด แล้วsort จากมากไปน้อย
5 print ตัวที่ 1 กับตัวที่ 2 ออกมา
```

## 4. วิธีสุดท้ายที่ใช้จริง

เปลี่ยนวิธีนิดหน่อย เพราะวิธีแรกต้องคูณทุกคู่ ถ้ามีดมีเยอะๆจะได้พื้นที่เป็นล้านชิ้นซึ่งช้าและเปลืองเกินไป

1. หาความกว้างกับความสูงของแต่ละช่องเหมือนเดิม
2. sort ความกว้างกับความสูงจากมากไปน้อย
3. ชิ้นที่ใหญ่สุดคือ ความกว้างที่มากสุด x ความสูงที่มากสุด
4. ชิ้นที่ใหญ่รองลงมาต้องเป็นอย่างใดอย่างหนึ่ง คือ กว้างมากสุด x สูงอันดับสอง หรือ กว้างอันดับสอง x สูงมากสุด เลยใช้max เลือกตัวที่มากกว่า
5. print ทั้งสองค่าออกมา

ที่ใช้ได้เพราะโจทย์บอกว่า M N มีอย่างน้อย 1 ใบ แปลว่าจะมีความกว้างกับความสูงอย่างน้อย 2 ค่าเสมอ ไม่ต้องกลัวว่าindex จะหลุด
