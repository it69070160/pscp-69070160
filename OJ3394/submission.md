## 2. ความเข้าใจโจทย์ของฉัน

โจทย์ต้องการให้หาว่าถ้าส่งข้อความให้นักเรียนคนที่ S แล้วข้อความถูกส่งต่อไปเรื่อยๆ จะมีนักเรียนได้รับข้อความทั้งหมดกี่คน

input: บรรทัดแรกคือ N กับ S ใช้split แยกเป็นint
อีก N บรรทัดคือหมายเลขนักเรียนที่คนที่ i จะส่งต่อให้ ถ้าเป็น 0 แปลว่าไม่ส่งต่อ

output: จำนวนนักเรียนที่ได้รับข้อความทั้งหมด รวมคนที่ S ด้วย

constraints: ข้อความอาจวนกลับมาหาคนเดิมได้ ถ้าไม่ดักไว้โปรแกรมจะวนไม่จบ ต้องจำไว้ว่าใครเคยได้รับแล้ว และแต่ละคนส่งต่อได้ไม่เกิน 1 คน

## 3. แผนแรกของฉัน

```text
1 รับค่า N กับ S เป็นint
2 สร้างlist เก็บว่าแต่ละคนส่งต่อให้ใคร โดยใส่ 0 ไว้ตำแหน่งแรกก่อน เพื่อให้indexตรงกับหมายเลขนักเรียน ไม่ต้องมาลบ 1 ทุกครั้ง
3 ใช้for loop ตามจำนวน N รับค่าแล้วappend ลงlist
4 สร้างset ไว้เก็บนักเรียนที่ได้รับข้อความแล้ว และตั้งตัวแปร now = S คือคนที่ถือข้อความอยู่ตอนนี้
5 ใช้while loop โดยมีเงื่อนไขว่า now ต้องไม่เป็น 0 และ now ต้องยังไม่อยู่ใน set
  ในloop ให้add now ลง set แล้วเปลี่ยน now เป็นคนที่ now ส่งต่อให้
6 พอหลุดloop ให้print len ของset ออกมา
7 ทดสอบกับtestcase ที่โจทย์ให้มาทั้ง 5 อันว่าตรงมั้ย
```
